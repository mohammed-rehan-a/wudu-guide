# 🕋 دليل الوضوء المرئي — Visual Wudu Guide

An interactive, responsive, multilingual step-by-step visual and auditory guide to ablution (Wudu / صفة الوضوء), featuring official recitation audios and demonstrative videos from the Haramain platform.

## ✨ Features

- **Step-by-Step Interactive Guide**: Complete sequence from Niyyah to feet washing.
- **Multilingual Support**: Supports Arabic, English, Urdu, French, Indonesian, Turkish, Bengali, Hindi, Kannada, Tamil, Telugu, and Marathi.
- **Synchronized Audio & Video**: Demonstrations and recitations for each step.
- **Auto-Play Mode**: Seamless step-by-step auto advance.
- **Accessibility & Responsive Design**: Dark mode aesthetic with high contrast and smooth micro-animations.
- **Developer Portfolio**: Integrated personal portfolio accessible via footer credit.
